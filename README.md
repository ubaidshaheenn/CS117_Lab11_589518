\# Storage Estimator



\## Purpose

Estimates the total storage needed for a number of files, shown in KB and MB.



\## How to run

python storage\_estimator.py



\## Example

Input:

How many files? 100

Average file size in KB? 500



Output:

Total storage (KB): 50000.0

Total storage (MB): 48.83
